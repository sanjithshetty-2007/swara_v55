# ISL Sign Language Assets — Credits

## Source

The sign language GIF animations and fingerspelling letter images in this directory
originate from the following open-source project:

**Repository:** [satyam9090/Automatic-Indian-Sign-Language-Translator](https://github.com/satyam9090/Automatic-Indian-Sign-Language-Translator)

This repository is itself forked from:

**Original:** [sakurakhadag/Speech-to-Indian-Sign-Language-Translator](https://github.com/sakurakhadag/Speech-to-Indian-Sign-Language-Translator)

## Contents

- **`gifs/`** — Animated GIF demonstrations of ISL phrases (e.g. "good morning", "how are you")
- **`letters/`** — Static images of ISL fingerspelling for individual letters (a–z)

## Usage

These assets are used in the ISL Translator application to render sign language
translations. Phrase GIFs are keyed by their filename (lowercase, without extension)
in the application's dictionary lookup system.
